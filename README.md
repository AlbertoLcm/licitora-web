# Oltech Atlas

Template frontend para una plataforma inteligente de gestión de licitaciones, construido con React, Vite, TypeScript y Tailwind CSS.

El prototipo incluye un Radar CompraMX simulado: monitoreo de publicaciones, descarga de anexos, calificación por IA, decisión humana antes de iniciar el proceso y matching RAG con el historial documental de la empresa.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar para producción

```bash
npm run build
```

El proyecto utiliza información simulada y no incluye backend, autenticación real ni persistencia de datos.
